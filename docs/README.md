# Documentación

La memoria original (PDF, en catalán, 373 páginas) **no se incluye en el repositorio** porque contiene
credenciales y posibles datos personales en capturas y código. Si quieres publicarla, antes hay que:

1. Revocar/cambiar todas las contraseñas que aparecen en ella.
2. Tapar o eliminar datos personales (correos, DNI de ejemplo, fotos).
3. Subirla como *Release* de GitHub o enlazarla desde Drive, mejor que dentro del repositorio (pesa ~60 MB).

Resumen por módulos en [`modulos.md`](modulos.md).
